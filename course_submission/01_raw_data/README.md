# 原始数据

本目录保存 Kaggle House Prices - Advanced Regression Techniques 官方数据文件。

文件说明：

- `house-prices-advanced-regression-techniques/train.csv`：训练集，包含房屋特征和 `SalePrice`。
- `house-prices-advanced-regression-techniques/test.csv`：测试集，只包含房屋特征。
- `house-prices-advanced-regression-techniques/sample_submission.csv`：Kaggle 提交格式样例。
- `house-prices-advanced-regression-techniques/data_description.txt`：字段说明。
