# 02. Data Understanding

## 数据文件

原始数据位于：

```text
house-prices-advanced-regression-techniques/
```

其中：

- `train.csv`：训练集
- `test.csv`：测试集
- `sample_submission.csv`：提交格式示例
- `data_description.txt`：字段说明

## 数据规模

当前数据规模：

| 数据集 | 行数 | 列数 |
| --- | ---: | ---: |
| train.csv | 1460 | 81 |
| test.csv | 1459 | 80 |
| sample_submission.csv | 1459 | 2 |

训练集比测试集多出的唯一字段是：

```text
SalePrice
```

这就是我们要预测的目标值。

## 字段类型

训练集共有 80 个输入特征，大致可以分成：

- 数值特征：面积、年份、数量、评分等
- 类别特征：街区、房屋类型、装修质量、销售类型等
- 序数特征：质量等级，例如 `Ex`、`Gd`、`TA`、`Fa`、`Po`

一个重要点是：有些看起来是数字的字段，其实更适合作为类别处理，例如：

- `MSSubClass`
- `MoSold`
- `YrSold`

这些字段的数值大小本身不一定代表线性大小关系。

## 目标值分布

`SalePrice` 有明显右偏：

| 指标 | 数值 |
| --- | ---: |
| mean | 180921.20 |
| median | 163000 |
| min | 34900 |
| max | 755000 |
| skew | 1.8829 |
| log1p skew | 0.1213 |

所以 baseline 中对 `SalePrice` 使用了 `log1p` 变换。

## 缺失值情况

缺失最严重的字段包括：

| 字段 | 训练集缺失比例 | 解释 |
| --- | ---: | --- |
| `PoolQC` | 99.52% | 多数房子没有泳池 |
| `MiscFeature` | 96.30% | 多数房子没有杂项设施 |
| `Alley` | 93.77% | 多数房子没有巷道 |
| `Fence` | 80.75% | 多数房子没有围栏 |
| `FireplaceQu` | 47.26% | 没有壁炉时为空 |
| `LotFrontage` | 17.74% | 临街宽度缺失 |
| `Garage*` | 约 5.55% | 没有车库 |
| `Bsmt*` | 约 2.5% | 没有地下室 |

这里最关键的判断是：很多缺失值不是脏数据，而是“没有该设施”的业务含义。因此不能简单全部删除，也不能全部填均值。

## 关键强相关特征

与 `SalePrice` 相关性较高的数值特征：

| 特征 | 相关系数 |
| --- | ---: |
| `OverallQual` | 0.791 |
| `GrLivArea` | 0.709 |
| `GarageCars` | 0.640 |
| `GarageArea` | 0.623 |
| `TotalBsmtSF` | 0.614 |
| `1stFlrSF` | 0.606 |
| `FullBath` | 0.561 |
| `YearBuilt` | 0.523 |
| `YearRemodAdd` | 0.507 |

这说明房屋质量、居住面积、地下室、车库、建造年份是主要信息来源。

## 明显异常点

发现两个经典异常点：

| Id | GrLivArea | SalePrice | 说明 |
| ---: | ---: | ---: | --- |
| 524 | 4676 | 184750 | 面积极大但价格偏低 |
| 1299 | 5642 | 160000 | 面积极大但价格偏低 |

baseline 中删除了这两个训练样本。

删除理由：这两个点会干扰模型学习“面积越大价格越高”的主趋势，尤其会伤害线性模型。
