# 01. Problem Overview

## 题目是什么

这是 Kaggle 的经典入门回归题：**House Prices - Advanced Regression Techniques**。

我们拿到的是美国 Ames 房屋交易数据。每一行是一套房子，每一列是这套房子的某种属性，例如：

- 房屋面积
- 建造年份
- 整体质量
- 地下室情况
- 车库情况
- 街区位置
- 装修质量
- 销售月份和销售类型

训练集里有真实成交价 `SalePrice`，测试集里没有。我们的任务是根据训练集学到的规律，对测试集里的房子预测 `SalePrice`。

## 机器学习任务类型

这是一个监督学习中的 **回归问题**。

- 输入：房屋的 80 个原始特征
- 输出：连续数值 `SalePrice`
- 目标：让预测价格尽可能接近真实成交价格

## 评价指标

Kaggle 该题使用的核心指标是 RMSLE，本质上可以理解为：

1. 先对真实价格和预测价格取 log
2. 再计算 RMSE

因此，在建模时我们直接使用：

```python
y = np.log1p(train["SalePrice"])
```

模型预测完成后，再用：

```python
prediction = np.expm1(log_prediction)
```

把结果还原成真实价格尺度。

## 为什么要对 SalePrice 取 log

房价数据通常是右偏分布：大多数房子集中在普通价格区间，少数豪宅价格很高。

当前训练集里：

- `SalePrice` 原始偏度约为 `1.88`
- `log1p(SalePrice)` 后偏度约为 `0.12`

这说明取 log 后目标值更接近正态分布，线性模型和很多树模型都会更容易学习。
